# Hi, I'm Zachary Maness

I'm an aspiring data analyst based in the Memphis area. I enjoy taking messy information, finding the useful story inside it, and turning it into dashboards or tools that people can actually use.

I earned a bachelor's degree in computer science with a minor in data analytics from Southern New Hampshire University and completed the Google Data Analytics Professional Certificate. My current focus is building practical portfolio projects that connect technical analysis with real business questions.

## Featured Projects

### [ETF Performance Analysis Dashboard](https://github.com/ZachPoli/etf-performance-analysis-dashboard)
Combined and cleaned historical market data, calculated five-year returns for 341 U.S.-listed ETFs with SQL, and built an interactive Tableau dashboard for comparing performance.

### [Inventory Tracking and Reporting App](https://github.com/ZachPoli/inventory-tracking-reporting-app)
Built a Python and PostgreSQL desktop application that helps organize inventory, validate records, create barcodes, and export clean data for reporting.

### [Rescue Dog Selection Dashboard](https://github.com/ZachPoli/rescue-dog-selection-dashboard)
Created an interactive dashboard that connects to MongoDB and helps a rescue organization filter shelter records to identify dogs suited for specialized training programs.
