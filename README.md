## What I'm Building Now

### [Career Command Center — Public Case Study](projects/career-command-center.md)
A local-first career workflow application that discovers and verifies job postings, ranks opportunities against candidate evidence, tracks applications, analyzes ATS fit, and generates evidence-based tailored resumes. The system combines job discovery, structured evidence, resume versioning, and an external-feedback loop for improving match quality.

**Core ideas:** Python, SQLite, OpenAI API/web search, document generation, ATS analysis, workflow automation, evidence traceability.

### [FamiliarVoice — Public Case Study](projects/familiarvoice.md)
An accessibility-focused Android prototype inspired by my blind father and grandmother. FamiliarVoice detects supported incoming messages and turns them into sender-specific familiar-voice audio that can play through the phone's active media output, including smart glasses.

**Built with:** Kotlin, Android, FastAPI, Python, ElevenLabs, hosted backend services, physical Android devices, and Ray-Ban Meta glasses.  
**Source:** intentionally private while the project continues development.

### [Environmental Pneumatics Inventory System](https://github.com/ZachPoli/inventory-tracking-reporting-app)
I independently designed and built a Python/PostgreSQL inventory system while working as a CNC laser operator at Environmental Pneumatics. I used it in my actual laser workflow to track sheet-metal inventory by type, gauge, size, location, and quantity, with barcode, export, backup, and validation tooling.

### [Zenith Capital Group](https://github.com/ZachPoli/zenith-capital-group)
My software-business and product-development umbrella for turning useful applications into sustainable products and, over time, a broader technology business.

### [ETF Performance Analysis Dashboard](https://github.com/ZachPoli/etf-performance-analysis-dashboard)
Combined and cleaned market data, used PostgreSQL/SQL to calculate five-year performance across 341 U.S.-listed ETFs, and built an interactive Tableau dashboard for exploring the results.

### [Driver Pay Calculator](https://github.com/ZachPoli/driver-pay-calculator)
A reusable Excel model that turns mileage and paid-hour inputs into daily and weekly gross-pay estimates—an example of translating firsthand operational knowledge into a practical tool.
